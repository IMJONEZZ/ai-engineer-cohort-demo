# Before the cohort

Complete the three steps in this folder before Day 1. The goal is a shared
baseline so the first morning is hands-on, not setup.

Budget about two hours end to end. If anything blocks you, raise it in the
cohort channel *before* Day 1 — the first lab assumes a working environment.

## Checklist

- [ ] Python 3.11+ and git installed, editor of choice signed in
- [ ] Course virtual environment created and Jupyter launching
- [ ] Program-issued API keys stored in `.env` (never committed)
- [ ] A local model downloaded and answering a test prompt
- [ ] First notebook (`Day_1_Foundations/sessions/S1_…`) opens and runs top to bottom
